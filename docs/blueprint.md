# **App Name**: Whyte Interiors

## Core Features:

- Design Portfolio: Showcase Whyte Interior Designs' completed projects (residential & commercial) with high-quality images. Doubles as a picture blog.
- Service Offerings: Clearly list and describe the interior design services offered: consultancy, design & build, refresh services. Target residential & commercial clients.
- Contact Form: Enable potential clients to contact Whyte Interior Designs directly through a web form. Use Zod for validation and Zustand for state management, if needed.
- Style Quiz: Provide a style quiz that gives interior design recommendations based on user input. This recommendation will act as a tool, allowing the firm to customize a quote for each lead.
- Functional Call to Actions: Implement clear and functional call-to-action buttons across the site to encourage user engagement.

## Style Guidelines:

- Primary color: Pastel purple (#D8BFD8) to evoke a sense of luxury and sophistication.
- Background color: Whyte (#F8F8FF), providing a clean and classic backdrop.
- Accent color: Dark lavender (#73648A), to provide contrast against the primary and background, and add to the luxury aesthetic.
- Body and headline font: 'Inter' (sans-serif) for a modern and clean look. Note: currently only Google Fonts are supported.
- Use minimalist and elegant icons to represent design elements and services.
- Maintain a clean and spacious layout with ample whitespace to emphasize the luxury feel. Default to Shadcn components.
- Subtle transitions and animations on page elements to create a refined user experience.
